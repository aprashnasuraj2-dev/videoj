# DHAGO submission readiness

The final release candidate is validated through one exact-build gate: typecheck, production build, Chromium functional tests, compact Firefox/WebKit-engine proof, immutable build staging, public-manifest publication, branded-Chrome public smoke, Lighthouse measurement and final evidence capture.

The final evidence artifact is the manual attachment source. It contains the active hero, 8-second interaction loop, finished-cloth state, active mobile capture, standalone Stress Lab/browser-loader evidence, layered-weft fixture, reusable ribbon, public integration proof, measured performance/size evidence and capture provenance bound to the public release fingerprint.

No contest terms are accepted and no entry is claimed by automation. Genuine outside human validation is recorded only if actually obtained. Safari on macOS, physical Android Chrome, physical iPhone Safari and VoiceOver/NVDA remain `NOT TESTED` unless a real device/pass is performed; Playwright WebKit must never be relabeled as Safari.
