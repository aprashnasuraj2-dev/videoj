# SUTRA development setup

Use Node.js 24 and the pinned dependencies required by the SUTRA workflow. Run `node --test packages/sutra-knowledge/test/*.test.mjs` for the bounded kernel suite. For the current browser laboratory and exact build steps see [apps/sutra-v2/README.md](apps/sutra-v2/README.md), [knowledge package](packages/sutra-knowledge/README.md), and [workflow](.github/workflows/sutra-v2-knowledge.yml). Additional Go, Python, WASM and browser checks are required for their respective profiles. No live provider key, paid inference or deployment is needed for the local knowledge tests. This is a development candidate, not a production installation guide.
