### Source lifecycle

Observed and asserted:

- two simultaneous players keep independent reference state;
- 20 remove/reinsert cycles do not multiply the Temporal Lens or handlers;
- a frame callback completing after disposal cannot commit stale state;
- stale callbacks cannot win after Close or Clear;
- an old source callback cannot overwrite a newer valid pin;
- same-URL reload clears the previous source epoch;
- latest valid source/reference state wins;
- a failed re-pin retains the prior valid reference;
- metadata-pending, NaN/unknown duration, waiting/frame-pending, seeking, invalid picture, ended-ready, live/timeline-unavailable and source-error states are explicit;
- pausing while waiting remains paused after recovery;
- no `NaN` or `Infinity` presentation is accepted.

Two concrete defects were found by this gate and fixed:

1. the relation layer had a CSS display rule that could visually override HTML `hidden`; AFTERIMAGE now has a scoped `.afterimage [hidden]` rule;
2. detach/reinsert during a pending capture could leave the reused Pin button transiently disabled; a new mount resets that transient state.

Neither fix changes Pin/Split/Now semantics or media transport.

### Packed external consumer

A fresh temporary application installed the actual tarball produced by `npm pack`, supplied its own generated video, poster and captions, and exercised both package entries.

Verified:

- `afterimage-video-skin/base` mounts an ordinary player and does not register/import Temporal Lens behavior;
- the enhanced entry supports two isolated instances;
- Play/Pause, Seek, Mute and real captions operate with host-owned media;
- manual playing Pin does not pause or seek backward;
- Close → Compare → Clear and dispose/remount work;
- the packed runtime excludes demo/tests/docs/artifacts and contains no WATERLINE media coupling, Apollo/Aafnai runtime dependency, DETOUR dependency, challenge-host dependency, Mux management credential or bearer credential.

## Deliberate exclusions

- Playback Settings / playback-rate UI was evaluated but not added. At 240/320/390px the current direct Play, Seek, Mute/Volume, Captions, Fullscreen and Pin presentation already fits truthfully; adding another first-use control would increase density without strengthening the Temporal Lens thesis.
- No Return/Stay/checkpoints/navigation history, multiple held places or automatic seek-back behavior was introduced.
- No DETOUR runtime code or visual language was imported.

## Regression / concept-drift audit

The hardening architecture tests continue to reject programmed `.play()`, `.pause()` and `currentTime =` behavior inside the manual Temporal Lens. The manual feature still owns one real reference frame, Pinned/Split/Now, one seam, one real seek rail and independent conventional transport. The existing authored comparison remains the only documented intentional seek exception.

**Concept drift result: No.** The changes are lifecycle, truthful-state, portability, presentation-state and evidence hardening only.
