DHAGO is a standards-based Video.js v10 skin with a host-neutral ribbon primitive and a browser-side resilience lab. This page documents the integration contract used by the public release without requiring access to the private project workspace.

Player createDhagoPlayer(options) Ribbon chapters + tracks + playback state Stress Lab browser adapter contract License Apache-2.0 challenge release

01 / Player API

Mount the skin.

The challenge release uses this public integration shape. Media truth stays with the browser/Video.js runtime; optional metadata is only rendered when supplied.

import { createDhagoPlayer } from './dhago/create-player';

const player = createDhagoPlayer({
  source: '/film.mp4',
  poster: '/poster.webp',
  chapters: '/chapters.vtt',
  captions: '/captions.vtt',
  surface: 'warm',
});

document.querySelector('#player').append(player);

02 / Mux delivery

Public playback ID, never API secrets.

When a public Mux playback ID is supplied, DHAGO uses the Video.js Mux adapter. A direct source can remain available as a compatibility fallback. Management credentials never belong in browser code.

const player = createDhagoPlayer({
  source: '/film.mp4',
  compatibilitySource: '/film.webm',
  playbackId: 'PUBLIC_PLAYBACK_ID',
  fallbackUrl: location.href + '?local',
  chapters: '/chapters.vtt',
  captions: '/captions.vtt',
});

03 / Layered weft

Authored metadata remains explicit.

Speaker, sponsor and custom lanes are not inferred from the film. A host must provide them. Malformed/duplicate input is bounded so it cannot break the primary seek control.

metadataTracks: [{
  id: 'speaker',
  label: 'Speakers',
  kind: 'speaker',
  cues: [
    { start: 0, end: 18, label: 'Host' },
    { start: 18, end: 42, label: 'Guest' },
  ],
}]

04 / Reusable ribbon

Host-neutral timeline primitive.

The Woven Time Ribbon is deliberately smaller than a player library. It accepts chapter/track geometry and playback state, then returns normalized state while leaving transport ownership with the host.

Open the live two-host ribbon proof ↗

const ribbon = createWovenRibbon({
  chapters,
  tracks,
  onSeek(time) {
    media.currentTime = time;
  },
});

ribbon.update({
  currentTime: media.currentTime,
  duration: media.duration,
  buffering,
  droppedFrames,
  renditionHeight,
});

05 / Stress Lab

Test another skin without cloning DHAGO.

The public Stress Lab accepts a browser-loadable ESM adapter URL or a local .js/.mjs file. Third-party code runs inside an opaque-origin sandbox and returns only structured results to the parent page.

Open the working browser tool ↗

export default {
  name: 'My player',

  async mount(host, input) {
    const root = mountMyPlayer(host, input);

    return {
      root,
      media: root.querySelector('video'),
      destroy() {
        root.remove();
      },
    };
  },
};

Truth boundary

What this page does not claim.

It does not claim npm publication, official Video.js adoption, Safari/macOS testing, physical-phone testing, or real screen-reader validation. Those remain separate release facts. The public integration contract documents the challenge candidate; it is not a package-registry announcement.
