Adapter contract / standalone public guide

Bring a compatible player. Keep the boundary small.

Stress Lab does not require access to DHAGO's private project workspace. A browser-loadable adapter only needs a name and a mount function. Remote adapters run in a sandboxed iframe with scripts enabled but without same-origin privilege; local adapter files are read in the browser and are not uploaded.

export default {
  name: 'My player',
  async mount(host, input) {
    const root = await mountMyPlayer({
      host,
      source: input.source,
      poster: input.poster,
      chapters: input.chapters,
      captions: input.captions,
    });

    return {
      root,
      media: root.querySelector('video'),
      destroy() {
        root.remove();
      },
    };
  },
};

URL mode

The adapter URL and every imported dependency must permit browser module loading under CORS. A blocked URL is NOT RUN, not a skin failure.

Local file mode

Choose a single .js or .mjs file. It is converted to a Blob module inside the isolated frame. Relative filesystem imports are therefore not supported.

Security model

The parent validates the iframe window plus a random session identifier before accepting results. Third-party code never receives allow-same-origin and cannot inject arbitrary result HTML into the parent UI.

Truth model

Forced colors and reduced motion are only marked RUN when real media queries are active. Live/DVR and real 400% zoom remain manual gates unless genuinely supplied.

What is demonstrated / what remains to be checked

Tests should expose limitations, not hide them.

Media decoding, live DVR, iOS native fullscreen, external casting, physical touch cancellation, real browser zoom and screen-reader behavior need genuine device/source conditions. A browser fixture can model geometry or induce an error, but it cannot manufacture those proofs.
