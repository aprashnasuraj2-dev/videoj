# SUTRA orbital frontend reference adaptation

Reference archive inspected: outputs/src/components/agents/AgentAvatar.tsx (six avatar families, spring and trails), AgentOrchestrator.tsx (role/state metadata, workflows, simulated transport), pages/AgentWorkspace.tsx (swarm/comms/config), RingMap.tsx (rotation and zoom), styles/tokens.css (Paper & Phosphor), EraToggle.tsx, AppShell.tsx, Guestbook.tsx and public manifest/service worker. The archive's HTML is a Vite mount point, not a standalone rendered site.

## Product boundary
- Twelve stations represent actual SUTRA capabilities rather than fictitious web communities.
- Six avatars are presentation roles. Explicit deterministic rehearsal is separate from actual local scripted council telemetry. A response event is not proposal admission; admitted proposals are logged separately.
- No secret or model credential is persisted by the orbital layer. Connection drafts stage into the two existing council slots; temperature/fallback/priority are not live routing settings. Use the existing local operator plan for actual approved execution.
- No hidden model reasoning is fabricated. Activity is public operation summaries or clearly labeled synthetic rehearsal steps.
- The signed guestbook is explicitly enabled and stored locally; a non-extractable P-256 key signs only user notes. It is not canonical verification or model identity. The activity journal is unsigned.
- PWA registration is opt-in; only the offline fallback and immutable hashed assets are cached. Navigations are network-first, and offline cannot certify or change a conclusion. No secret/source data is cached by the service worker.
- The previous guided debugger remains at ?surface=debugger. Its original first-viewport test is preserved on that route. The orbital landing has a separate first-viewport regression.
- No new dependencies or remote fonts. Fonts are system fallbacks, SVG uses DOM primitives rather than React/Motion/Canvas. The 1997 skin is local and reduced motion is respected.

## Rehearsal routing
Configured model descriptors form a shared connection pool. Rehearsal uses the highest-priority configured route without per-avatar assignment. Simulated units are not actual tokens or billing. The actual local council still uses its own two-slot configuration and consent. Modern light/dark and 1997 treatments preserve the same investigation engine; the obsolete blink/marquee behavior is intentionally replaced by a static retro ticker.

## Run-scoped council activity
The scripted council emits a versioned metadata-only envelope with run identity, increasing sequence, fixed origin, agent slot, round and phase. The independent projection rejects stale, duplicate, out-of-order and malformed events; cancellation closes the emitter immediately. Transport responses are distinct from proposal admission. The two actual configurable slots have their own inspector; the six rehearsal avatars no longer fabricate role attribution or handoffs from two-slot events. This is unsigned UI telemetry, not a receipt or a source of permission or computation authority.

## Shared investigation dependency projection
The master workbench and orbital Evidence, Quantities, Interpretations and Compute stations consume one read-only projection. Evaluated versions use the canonical report graph; drafts display only selected spans and declared ancestry. Traversal indexes edges in O(V+E) time and handles cycles without treating ancestry as independence. The orbital station inspector shows bounded upstream/downstream relationships and opens the full existing graph; no new knowledge authority or fabricated graph links. Source and binding changes now refresh the orbital inspector even when counts are unchanged.

## Demand-driven orbital rendering
The orbital scene no longer schedules a permanent idle requestAnimationFrame loop or idle breathing animation. A coalesced presentation clock wakes on motion, rehearsal, navigation, and visibility changes; settled/hidden scenes stop rendering, and hidden browser tabs suspend the clock. CSS avatar animation is paused in idle states. Actual frame-time and battery improvements remain to be measured on devices. Browser regressions inspect the new council activity projection and real dependency inspector.

The activity envelope now declares the exact participating slot IDs on start and rejects unknown, duplicate, or over-capacity teams. The projection supports the kernel's existing maximum of four slots; this does not expand the browser's two-slot consent UI or the separate expression slot-round budget. Browser coverage additionally exercises immediate cancellation with zero admitted proposals.
