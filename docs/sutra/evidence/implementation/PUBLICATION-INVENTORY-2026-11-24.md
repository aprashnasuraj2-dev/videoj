# Development publication inventory and bounded read policy

The learner build emits /agents/artifact-inventory.json. It lists the exact published network identity paths, manifest, links, current graph versions and aliases, and built browser entry/module/style paths with byte lengths and SHA-256. Alias/version drift and missing runtime files fail the build. It is a same-owner integrity inventory, not a signature, runtime trust grant, or evidence that a production URL is live. /api/status is the separate top-site inference-discovery path; no peer manifest can choose a provider/model.

Local static read policy: one attempt by default. The explicit scripted network-test host opts into at most one additional same-origin credentialless GET across the entire load, only after a received 502/503/504 before data parsing. No retry on ambiguous transport, malformed JSON, 404, redirect, partial read, cancellation, model call, write or external peer contact. Actual attempt events expose artifact kind and count, not arbitrary response contents or URLs. Deadline remains shared. A persistent failure stays incomplete. Re-run is explicit; no production or external contact is authorized.
