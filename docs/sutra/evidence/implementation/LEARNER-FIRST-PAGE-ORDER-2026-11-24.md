# Learner-first page order — 2026-11-24

The visible page now keeps the core learning journey contiguous: lesson/source inspection → direct or optional model retrieval → source comparison → explicit local review. Developer orchestration, peer workbench and consent-exercise controls remain fully available but appear after a clearly labeled optional interoperability-lab divider.

No developer capability was removed or hidden. This is an information-architecture change: a first-time judge no longer has to cross three technical sections before reaching comparison and review. The hero browser test asserts DOM order so future refactors cannot accidentally put developer tooling back into the middle of the learner task.
