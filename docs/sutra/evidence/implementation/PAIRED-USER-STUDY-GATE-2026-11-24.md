# Paired user-study scoring protocol — implementation readiness

A deterministic ten-participant, two-method, two-variant counterbalanced study scorer is available under `tools/sutra-user-study/`. It preserves every paired row, requires success to include valid evidence, refuses speed claims when evidence accuracy is not comparable, and leaves a manual-search win negative.

No participant data exists and no user-study checklist item is satisfied by this code. The scorer is readiness infrastructure for phases 074–075 only.
