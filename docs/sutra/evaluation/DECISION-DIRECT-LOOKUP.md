# Use the simplest sufficient evidence path

The engineering-v1 benchmark found exact cue selection 20/20 in both the direct and delegated paths, while the latter made 90 scripted calls and 90 source-handler RPCs. Direct lookup requires zero model calls and zero network requests against the already loaded synthetic catalog. It is now a first-class visible option for literal wording, not a hidden replacement for agent composition.

The user can retrieve a catalog-matched receipt, inspect its exact source/version/time, seek only when actual native media is loaded, and explicitly review that exact receipt before saving. A changed query clears stale actions; no match abstains. Semantic questions remain a separate opt-in configured-provider workflow. Do not infer semantic or factual support from literal matching, or generalize in-process timings to live inference.
