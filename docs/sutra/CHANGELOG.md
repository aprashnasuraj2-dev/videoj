# SUTRA changelog

SUTRA has **no public release yet**. This file is intentionally conservative: development commits and private candidates stay under **Unreleased** until a real public version is created from an immutable source revision.

## Unreleased

- Evidence-linked learner, restricted browser runtime, source/evidence tools, consent boundary, peer/source integration, optional inference boundary and reusable Open Kit are under active development.
- Development fixtures, CI candidates and draft PRs are not release versions.
- Live provider economics, rights-cleared final content, human/physical acceptance, public HTTPS interoperability and production release evidence remain separately gated.

## Version-entry rule

Create a dated version heading only after an actual public release exists. Each release entry must include:
- exact version/tag;
- immutable source SHA;
- public release date;
- public artifact/release identity;
- only changes actually present in that release;
- material compatibility/security notes and known limitations.

Do not convert a branch commit, CI artifact, private Open Kit candidate, staging build or proposed URL into a public-version changelog entry.
