# SUTRA V2 roadmap

The machine-readable source of detailed gate state is `roadmap.json`. Work selection is controlled by `CHECKLIST.md`.

## P0 — integrated product correctness

- Keep the knowledge compiler, persistent investigation history and browser workspace on one coherent contract.
- Preserve exact source/provenance identities across revision.
- Maintain deterministic replay parity and independent verification.
- Complete provider-neutral orchestration without giving models verification authority.
- Close security, credential, disclosure, recovery and rollback boundaries.
- Keep the standalone browser build reproducible from `apps/sutra-v2/`.

## P1 — investigation intelligence

- Improve semantic compilation and candidate-meaning review.
- Strengthen evidence acquisition and source economics.
- Expand counterfactual search and decisive-observation planning.
- Improve persistent revision, shared-descendant impact and branch comparison.
- Integrate specialist domain journeys through the same kernel.
- Preserve uncertainty instead of forcing consensus.

## P1 — evaluation

- Maintain frozen development and held-out datasets.
- Compare matched baselines with equal evidence/resource access.
- Measure coverage, correctness, review effort, latency, cost, revision effort and replayability.
- Preserve adversarial counterexamples and failed revisions.

## P2 — optional capabilities

- Web access remains disabled by default until separately approved and verified.
- External providers remain bounded by explicit credentials, budgets, destinations and disclosure.
- Public deployment and external evaluation require separate authorization.

No roadmap item is complete because documentation says so; exact implementation and verification evidence control acceptance.
