# SUTRA V2 — Living, verifiable knowledge

SUTRA maintains investigations as explicit, replayable computational knowledge rather than disposable chat answers.

Core flow:

**question → evidence → candidate interpretations → review → conditional computation → challenge → revision → impact analysis → replayable export**

The system keeps model proposals replaceable and separates deterministic verification from source truth, semantics, empirical support and decision authority.

## Current components

- Browser workspace: `apps/sutra-v2/`
- Knowledge kernel: `packages/sutra-knowledge/`
- Portable runtime: `packages/sutra-runtime/`
- Inference boundary: `packages/sutra-inference/`
- Consent boundary: `packages/sutra-consent/`
- API adapters: `services/sutra-api/`
