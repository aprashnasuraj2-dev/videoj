# Root ancestry and withdrawal previews

A root is a host-declared lineage, not a statistically independent measurement. The fixed case has exactly one admitted computational reading per active root. Original and copied byte identities remain visible; copies inherit the original declared parent and add no independent observation. Unknown copying, correlated errors, and factual truth remain outside the claim.

For each active root R, a world is compatible after a hypothetical single-root withdrawal exactly when every blocker in the verified world trace is R. The projected state of both target and separate control is computed from all such worlds; no worlds means CONFLICTED, identical decisions mean SUPPORTED or REFUTED, mixed decisions mean UNDERDETERMINED. This does not privilege a contradictory source or recommend discarding it. The UI preview is read-only. Actual withdrawal remains a separate explicit event. The existing state and Proof Capsule already bind all required evidence and parent identities; there is no new standalone wire format.

Test every availability/reading/withdrawal configuration and both original-only and copied-root variants where valid. The projection must match a full actual kernel replay after removing that lineage, including all survivor identities, removed artifact identities, returned worlds and both claim states. Preserve the original event replay unchanged. Browser checks ensure the main diagnostic answers precede advanced inspection, exact ancestry is inspectable, both conflicting roots stay visible, and previews do not mutate the verdict.
