# World trace v1

The fixed model contains eight binary assignments of a, b and c. For each world the exact graph evaluates the target a+b≤1 and separate control c=1. A replayed admitted observation either agrees or disagrees with the world. The trace lists the expected and observed rational values, lineage and observation identity for each active reading, and all incompatible roots. A world survives iff its blocker set is empty. Withdrawing exactly its blocker set is necessary and sufficient to readmit that world in this declared fixture; supersets also readmit it. This is a counterfactual dependency, not authorization to remove a source or evidence that the world is true. Nine exact declared copies change the artifact count but add no computational observation. No probabilities or empirical independence are implied.

The JS trace checks the exact kernel projection against fixed binary assignments and both claim survival sets; an independent Python verifier reconstructs the anchored fixture and replays the events, then evaluates each hypothesis directly. Trace v1 is a separate derived artifact; existing debugger, diagnosis and capsule v1 formats stay unchanged. The UI shows the exact reason for each excluded world and readmission/exclusion counts relative to the previous local state. A new guide reset clears only ceremony progress, not the stored previous capsule.
