# SUTRA V2 current decisions

## Product identity

SUTRA is a living computational knowledge system. The product is the persistent investigation and its accountable revision history, not a generic chat interface.

## Verification authority

Models propose. Deterministic kernels verify only admitted computational obligations. Source truth, semantics, empirical support, freshness, applicability and external action authority remain separate.

## Persistence

Investigation history is versioned, branchable and replayable. Incremental reuse must preserve exact provenance and match fresh recomputation for the admitted model.

## Provider neutrality

Agent roles and investigation logic must not depend on a vendor. Credentials remain outside portable artifacts and are disclosed only to explicitly approved destinations.

## Interoperability

Portable agent/runtime components are reused where they improve investigation capability without surrendering caller policy, consent or verification boundaries.

## Optional web access

Web access remains disabled and unregistered by default. Activating it requires a separate architecture decision and security verification.

## Repository

The active repository contains only SUTRA V2 product source and reusable SUTRA infrastructure. Historical implementations remain in Git history rather than the active tree.

## Release

Source integration, CI, main-branch promotion, public deployment and external submission are distinct actions. Each requires the evidence and authorization appropriate to that action.
