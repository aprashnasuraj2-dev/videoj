# Contributing to SUTRA

Read [AGENTS.md](AGENTS.md), the [living knowledge mandate](docs/sutra-v2/LIVING-KNOWLEDGE.md) and [continuation contract](docs/sutra-v2/CONTINUE.md). Resolve exact remote CI, reuse existing components, add adversarial tests and update affected registers. Preserve old evidence and do not claim correctness beyond the admitted model. Node 24 knowledge tests: `node --test packages/sutra-knowledge/test/*.test.mjs`; full checks are defined in SUTRA workflows. Report unrun checks, failure behavior, scope, security and limits. No deployment, credentials, paid inference or release without authorization. Retain license and attribution for reused components.
