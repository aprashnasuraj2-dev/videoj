A note on real-world proof

Some experiences need the real device.

The original film stays available above while you explore these conditions. The browser cannot faithfully recreate a live broadcast, an iPhone’s native controls or an assistive-technology session.

  1. Live and time-shifted video. Check a genuine live source with a real seekable window before judging live-edge controls.
  2. iPhone, AirPlay and fullscreen. Try playback, rotation and external playback on the devices that actually provide those features.
  3. Zoom, touch and accessibility. Check 200–400% browser zoom, keyboard navigation, touch cancellation and a real screen reader.

A thoughtful interface should acknowledge what is still to be verified—not claim success on behalf of another device.

How connections and privacy work

Compatible connectors use JavaScript modules (.js or .mjs). Web addresses and imported dependencies must allow cross-origin loading. If a connector cannot load, its study is marked Not assessed—not a player failure. Local files are not uploaded by this site, but loaded code can make its own network requests. Only use code you trust.
