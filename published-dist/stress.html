1 / Load an adapter

Third-party code runs in a sandboxed, opaque-origin iframe. It cannot write arbitrary markup into this page. The built-in DHAGO adapter is the trusted reference specimen.

URL modules and every dependency they import must permit browser CORS. A blocked module is reported as NOT RUN, not as a skin failure. Local files execute only in the sandbox and are not sent to a backend.

What is demonstrated / what remains to be checked

Tests should expose limitations, not hide them.

Media decoding, live DVR, iOS native fullscreen, external casting, physical touch cancellation, real browser zoom and screen-reader behavior need genuine device/source conditions. A browser fixture can model geometry or induce an error, but it cannot manufacture those proofs.
