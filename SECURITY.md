# SUTRA security policy

Report vulnerabilities privately to the maintainer using GitHub private vulnerability reporting if available. Do not publish credentials or sensitive evidence. Treat documents, model outputs, peers, source metadata and imported artifacts as untrusted. Separate source integrity from authenticity, semantic and empirical validity, and operational authority. External model or peer contacts require explicit scoped consent, minimized disclosure, bounded budgets and cancellation. Preserve fail-closed admission, replay, rollback and recovery checks. See [threat model](docs/sutra-v2/THREAT_MODEL.md) and [continuation](docs/sutra-v2/CONTINUE.md). Tests are scoped evidence, not certification.
