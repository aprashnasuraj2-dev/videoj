# SUTRA agentic-site starter — 0.1.0-dev.1

Development-only, Apache-2.0 source example. Node 22+, modern browser; no dependencies to install. Run `npm install --ignore-scripts --offline`, `npm run verify:vendor`, `npm test`, then `npm start`. Open http://127.0.0.1:4177. The app uses a pinned nsDeploy runtime, two synthetic agents and a separate, explicit single-use local action. All included fixture content is synthetic, not a factual lesson. No live inference, publisher adoption or official certification is claimed.

Public paths: /agents/agent-manifest.json, /agents/learner.network.json, /agents/links.json. Exact network name: learner. A consumer may refer to a second origin's /agents/learner; the loader resolves the manifest and graph, not executable code. Run a second server with PORT=4178 npm start. The test demonstrates denial before transport and separate manifest/graph approval over actual loopback HTTP; the browser UI intentionally restricts connect-src to same origin. Never weaken CSP just to demonstrate a peer. For a published site, select a specific HTTPS origin, add it to the deployed CSP, confirm each external contact and check browser CORS. Do not label loopback as public HTTPS or independent adoption.

Default inference is explicitly scripted. To integrate live inference, the host must inject a caller-approved provider adapter and a bounded same-origin server proxy, pin the model, apply quotas and cancellation, and store keys server-side. Do not put secrets into graphs, public files or the browser. No arbitrary remote tools, authenticated MCP, writes or provider are enabled in this starter. A failed router must not silently fall back to scripted success.

The preview server binds loopback only. For static deployment publish the explicitly allowed index/app/modules and /agents files with matching MIME, headers and no directory listing; do not publish the whole source directory. /agents JSON may be public CORS, without credentials. For production HTTPS test exact-name resolution, consent denial (zero outbound requests), missing graph, no HTML fallback, CSP, and versioned rollback. Retain LICENSE and the complete upstream vendor license/provenance material. Tests are project checks, not challenge certification.
