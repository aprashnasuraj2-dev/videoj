## Collision decision

- [mpv's documented marked seek](https://mpv.io/manual/stable/#command-interface-revert-seek-flags) can return to a user-marked timestamp after multiple seeks. This is functional prior art. DETOUR's differentiator is an exposed hold, persistent visual mark, one-click return and explicit discard in a conventional browser player.
- PRISM addresses precision and scene repetition, Chronoscope stores notes and Edit bay emulates editing navigation. None of the reviewed descriptions establishes the complete visible DETOUR flow. This is a sampled result. Late entrants can change it.
- Do not spend the remaining window on a map, waveform, loupe or chapter system. A separate route marker on a single conventional seek rail gives the held origin a testable role.
- Re-rank if a working current entry shows an exposed held place that survives multiple unrelated seeks and can return or be discarded with one action. Track WAYLINE in crop reviews so the shared accent treatment does not decide the visual identity.
