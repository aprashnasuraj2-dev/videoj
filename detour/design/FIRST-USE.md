# DETOUR first-use study

**Status:** Ready to run. Participant results are pending.

Run on the branch prototype with `npm ci` and `npm run dev` from `detour/`. Recruit viewers who have never tried DETOUR. Plan for five observations per task and at least two real touch runs for the live task. Prefer separate participants for the crop and live task to preserve first exposure. If the same people do both, rotate the order and record the exposure for every score.

## Tasks

| Task | Setup | Prompt | Record |
| --- | --- | --- | --- |
| Two-second recognition | Show the [320 px](evidence/phase2/bracket-320.png) or [768 px](evidence/phase2/bracket-768.png) player-only crop. Hide it after two seconds. | “What action did this player offer?” | Exact answer and whether the viewer recognized the option to return to an earlier saved moment. |
| Find and return | Give the participant a fresh player, paused at 00:42, with no point held. Start timing when the task is visible. | “You’re at 00:42. Look at 00:18, then get back to where you started.” | First control used, completion time, whether the viewer used the hold and return controls, and whether they asked for help. Record seeking back manually separately. |

Use the ordinary controls to set up the session. Keep the player visible and provide no hints before the attempt. For portrait touch runs record the device, browser and orientation. Describe the crop or alternate input after the test when needed to learn why an action was missed. Store only anonymous notes.
