## Scope and behavior

- **Thesis:** Keep where you are, explore anywhere in the video, and return in one action. Idle frame: at 00:42, “Keep my place” is beside ordinary playback. Held frame: the playhead has moved to 00:18, and the labeled Return action and separate mark still identify 00:42.
- **Five-second story:** pause at 00:42, press Keep, seek to 00:18, press Return, and show playback time back at 00:42. Longer proof: seek to 00:24 as well, verify the same held mark, then run a separate Stay path and show playback time does not jump.
- **Useful tasks:** In an interview, park at the reply before rechecking a prior question. In a tutorial, hold the step before finding the setup. In sports footage, save the post-play explanation before inspecting the buildup. In a short passive clip the viewer can ignore the place action and still use the usual controls.
- **Media-independent rehearsal:** Run the same flow on captioned interview and chapterless animation. Track availability may change captions, but it never changes the meaning of Hold, Seek, Return or Stay. Chapters, transcripts, thumbnails and metadata are optional media services.
- **User control:** Return lands on a real provider position and preserves play/pause state. Stay clears the mark without a seek. A source change invalidates both mark and pending return. A new manual seek takes precedence when a return is pending.
- **Skip for this milestone:** Persistent history, chapter mapping, range looping, social features and streaming adapters. Optional features can follow core baseline evidence.
