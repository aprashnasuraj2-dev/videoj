# DETOUR concept scope

Frozen for Phase 3 on 2026-11-15 Nepal time. The product promise is to keep a single moment, explore using the usual transport, and return to that original moment in one action. A different source starts a fresh session.

| Required behavior | Boundary |
| --- | --- |
| Keep my place | Save the exact current time for the active seekable video. Record one point per player instance. Keep does not play, pause or seek. |
| Explore | Ordinary playback and seeking carry on. Show the current playhead and a separate bracket at the held time, including when both represent the same timestamp. |
| Return to a time | Request one real seek and confirm the landing for the active origin and source. Preserve playback intent and focus. If return fails on a usable source, let the viewer try again or clear the point. |
| Stay here | Clear the point without seeking. A new media source or removal also clears the point and invalidates its pending return. |
| Expected playback | Keep play/pause, seek, time, mute or volume, and fullscreen easy to locate. Honor host-supplied captions and browser capabilities. Use the same core player for a replacement video. |

Persistent history, multiple places, accounts, share links, automatic chapters and extra themes are deferred. Streaming and integration bonuses can follow the local core and release evidence. Pausepoint remains an isolated backup. Evaluate a switch only if the exposed DETOUR flow collides with a working competitor or the core proof fails its repair gate.

The [first-use study](FIRST-USE.md) can still change wording or the marker after real viewer evidence. Keep that evidence distinct from the chosen scope and automated playback results.
